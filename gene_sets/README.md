# Gene sets

`hallmark_human.csv` contains the 50 **MSigDB Hallmark** gene sets (human gene symbols and Ensembl IDs), used by the app's **Pathways (GSEA)** tab.

- **Source:** Molecular Signatures Database (MSigDB) v7.5.1, Hallmark collection, exported from the `msigdbr` R package (v7.5.1).
- **Licence:** MSigDB gene sets are distributed under the [Creative Commons Attribution 4.0 International License (CC BY 4.0)](https://www.gsea-msigdb.org/gsea/msigdb_license_terms.jsp). © Broad Institute, Inc., Massachusetts Institute of Technology, and Regents of the University of California.
- **Credit:** Liberzon A, Birger C, Thorvaldsdóttir H, Ghandi M, Mesirov JP, Tamayo P. The Molecular Signatures Database (MSigDB) hallmark gene set collection. *Cell Systems*. 2015;1(6):417–425. https://doi.org/10.1016/j.cels.2015.12.004

Columns: `gs_name` (gene set), `gene_symbol`, `ensembl_gene`.
